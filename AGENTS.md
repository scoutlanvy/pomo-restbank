# Code Quality & Readability

- Write clean, readable, consistent, and maintainable code.
- Use balanced, natural spacing and readable multiline formatting.
- Avoid excessively long lines, unnecessary one-liners, and excessive blank lines.
- Keep related code together and separate distinct logical sections when helpful.
- Use concise comments only when they add useful context or clarify non-obvious logic.

# Code Organization & Architecture

- Prefer organizing code by feature or responsibility, reusing existing structures when appropriate.
- Proactively split files or create folders when they meaningfully improve readability, modularity, or maintainability—not solely based on line count.
- Prefer simple, shallow, and predictable folder structures. Avoid unnecessary nesting, fragmentation, abstractions, and overengineering.
- Follow existing AGENTS.md and ARCHITECTURE.md conventions when applicable.
- Keep architecture documentation updated when meaningful structural changes occur.
- Prefer cohesive modules with clear responsibilities over arbitrary file-size limits.
